# C2 Sticky Bomb

Плагин тактической взрывной системы для **SCP: Secret Laboratory**, созданный с использованием фреймворка **LabAPI**. Этот плагин добавляет в игру бросаемую липкую взрывчатку C2, интерактивные детонаторы, реалистичное разрушение окружения и специализированную контр-механику для роли сапёра.

---

##  Основные особенности

* **Липкая взрывчатка C2:**
  * Снаряды надежно прилипают к поверхностям при ударе, включая стены, полы и двери.
  * Запрещает игрокам просто подбирать активный заряд с пола.
  * Автоматически выдает игроку карманный детонатор (монетку) после успешной установки заряда.
* **Тактическая система сапёра:**
  * Специализированный набор сапёра, созданный на базе механики аптечки.
  * 4-секундный интерактивный процесс разминирования, требующий полной неподвижности (отслеживание перемещения и поворота камеры).
  * В случае успешного обезвреживания автоматически разрывает связь с детонатором, из-за чего подрывник видит ошибку «Связь потеряна».
* **Разрушение окружения и реалистичный бой:**
  * Каскадный визуальный и звуковой эффект тройного взрыва.
  * Реалистичный радиус поражения 7 метров с уменьшением урона в зависимости от расстояния.
  * Автоматически сносит вышибаемые двери (`BreakableDoor`) и разбивает стекла (`BreakableWindow`) в радиусе действия.
* **Кастомный динамический HUD:**
  * Контекстные подсказки на экране, направляющие игроков при удержании неброшенной C2, детонатора или набора сапёра.

---

##  Команды удаленного администрирования (Remote Admin)

* **`givec2`** (Алиас: `c2`) — выдает пользователю кастомную липкую взрывчатку C2.
* **`givesapper`** (Алиас: `sapper`) — выдает пользователю набор сапёра для поиска и обезвреживания вражеских зарядов.

---

##  Установка и требования

1. Убедитесь, что на вашем сервере запущен **LabAPI** (версии `1.1.7` или выше).
2. Скомпилируйте исходный проект под **.NET Framework 4.8** (`x64`).
3. Поместите скомпилированный файл **`C2StickyBomb.dll`** в директорию плагинов вашего сервера:
   `LabAPI/Plugins/`
4. Перезапустите сервер, чтобы загрузить плагин.
