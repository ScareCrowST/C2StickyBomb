# C2 Sticky Bomb

Плагин тактической взрывной системы для **SCP: Secret Laboratory**, созданный с использованием фреймворка **LabAPI**. Этот плагин добавляет в игру бросаемую липкую взрывчатку C2, интерактивные детонаторы, реалистичное разрушение окружения и специализированную контр-механику для роли сапёра.

---

##  Команды удаленного администрирования (Remote Admin)

* **`givec2`** (Алиас: `c2`) — выдает пользователю кастомную липкую взрывчатку C2.
* **`givesapper`** (Алиас: `sapper`) — выдает пользователю набор сапёра для поиска и обезвреживания вражеских зарядов.


---

##  Зависимости

* `Northwood.LabAPI` (≥ 1.1.7)
* `Northwood.PluginAPI` (≥ 12.0.0)
* `Mirror` (Сетевое взаимодействие)
* `MEC` (Корутины расширения MonoBehaviour)
